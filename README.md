# Personal Portfolio Website

## Description

This is a single page portfolio showcasing my skills and projects through a visually appealing interace and is implementation of the languages i'm learning which are HTML, CSS and JavaScript.The website features a burgundy and blush-pink color palette, a clean layout, smooth navigation, and dynamically rendered content using JavaScript.

## Features

- Sticky navigation bar with links to each section
- Hero section with an introduction
- About Me section with a short biography and profile image
- Skills section rendered dynamically using JavaScript
- Projects section rendered dynamically using JavaScript
- Contact section with email and GitHub link
- Responsive design for desktop, tablet, and mobile devices
- Interactive hover effects and smooth transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Setup

1. Clone the repository:

```bash
git clone git@github.com:im-jaz/Portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional software or dependencies are required since this project is built using HTML, CSS, and JavaScript.
